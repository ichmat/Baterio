# Baterio

Logiciel de gestion des chantiers, comprenant des fonctionnalités comme : 
- Gestion des fiches clients
- Gestion des devis
- Gestion des chantiers : attribution équipes de chantier
- Recherche global
- Plusieurs type de créations selon les cas
